## Problem 1

### Import and tidy NYC subway data

``` r
subway_df <- read_csv(
  "data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv", 
  na = c("", "NA", ".")) |>
  janitor::clean_names() |>
   select(line, station_name, station_latitude, station_longitude, 
          starts_with("route"), entry, vending, entrance_type, ada) |>
  mutate(entry = case_match(entry, "YES" ~ TRUE, "NO" ~ FALSE))
```

The cleaned subway dataset contains information about subway lines,
station names and locations, routes served, entrance and vending
characteristics, entrance types, and ADA compliance. The cleaning
process included cleaning the variable names, retaining the requested
variables, and converting `entry` from a character variable to a logical
variable. The resulting dataset contains `1868` rows and `19` columns.
The data are not completely tidy because the subway routes serving each
station are spread across several columns.

``` r
distinct_station_count = subway_df |>
```

### Reformat route data and summarize A train stations

``` r
subway_long =
  subway_df |>
  mutate(
    across(route1:route11, as.character)) |>
  pivot_longer(
    route1:route11,

    names_prefix = "route",
    values_to = "route_name",

a_train_station_count =
  subway_long |>

  distinct(line, station_name) |>

  subway_long |>
```

The A train serves `60` distinct stations and `17` of them are ADA
compliant.

## Problem 3

### Import and tidy baseline demographic data

``` r
baseline = 
  read_csv("data/data_mci/MCI_baseline.csv", skip = 1, na = ".") |>
  janitor::clean_names() |>
  mutate(sex = factor(sex, 
                      levels = c(0, 1), 
                      labels = c("Female", "Male")),
         apoe4 = factor(apoe4, 
                        levels = c(0, 1), 
                        labels = c("APOE4 non-carrier", "APOE4 carrier"))) |>
  filter(is.na(age_at_onset) | age_at_onset > current_age)
```

### Summarize participant characteristics

``` r
participants_recruited = nrow(baseline)

participants_developed_mci = sum(!is.na(baseline$age_at_onset))

average_baseline_age = mean(baseline$current_age)

women_apoe4_proportion =
  baseline |>
  filter(sex == "Female") |>
  summarize(proportion = mean(apoe4 == "APOE4 carrier")) |>
  pull(proportion)
```

The baseline dataset contains demographic and clinical information,
including `participant ID`, `baseline age`, `sex`, `education`,
`APOE4 carrier status`, and `age at MCI onset`. During the import
process, the first descriptive row is skipped, `"."` is treated as the
missing value, cleaned the variable names, converted sex and APOE4
status to factors, and removed participants who had developed MCI by
baseline. The resulting dataset contains `479` participants, `93` of
them developed MCI during follow-up. The average baseline age was
`65.03` years, and `30`% of the women were APOE4 carriers.

### Import and tidy longitudinal biomarker data

``` r
amyloid =
  read_csv("data/data_mci/mci_amyloid.csv", skip = 1, na = c("NA", "Na")) |>
   janitor::clean_names() |>
  rename(id = study_id) |>
  pivot_longer(baseline:time_8,
               names_to = "time",
               values_to = "amyloid_ratio") |>
  mutate(time = parse_number(str_replace(time, "baseline", "0")))
```

The longitudinal amyloid dataset was imported by skipping its first
descriptive row and treating both `"NA"` and `"Na"` as missing values.
The variable names are cleaned, renamed the participant identifier to
match the baseline dataset, converted the five measurement columns into
long format, and represented time as years since baseline. The resulting
dataset contains `487` participants and `2435` participant-visit records
across five possible measurement times. The key variables are `id`,
`time`, and `amyloid_ratio`, which represent participant ID, years since
baseline, and the amyloid $\beta$ 42/40 ratio respectively. While there
are `172` scheduled measurements have missing biomarker values.

### Compare participants across datasets

``` r
baseline_only = baseline |>
  distinct(id) |>
  anti_join(amyloid |> distinct(id), by = "id") 
  

amyloid_only = amyloid |>
  distinct(id) |>
  anti_join(baseline |> distinct(id), by = "id")
```

There were `8` participants who appeared only in the baseline dataset
and `16` who appeared only in the amyloid dataset. Some participants in
the amyloid-only group were excluded from the cleaned baseline dataset
because their recorded MCI onset age was less than or equal to their
baseline age, which indicating that they had already developed MCI by
the study baseline and therefore did not meet the inclusion criteria.

### Combine and export the demographic and biomarker data

``` r
mci_combined = inner_join(baseline, amyloid, by = "id") |>
  arrange(id, time)

write_csv(mci_combined, "data/data_mci/mci_combined.csv")
```

The combined dataset contains `471` participants, `2355`
participant-visit records, and `8` variables. Each row represents one
participant at one scheduled biomarker measurement time and includes
baseline demographic information, APOE4 carrier status, MCI onset
information, time since baseline, and the amyloid $\beta$ 42/40 ratio.
