``` r
   select(line, station_name, station_latitude, station_longitude,
```

The cleaned subway dataset contains information about subway lines,
station names and locations, routes served, entrance and vending
characteristics, entrance types, and ADA compliance. The cleaning
process included cleaning the variable names, retaining the requested
variables, and converting `entry` from a character variable to a logical
variable. The resulting dataset contains `1868` rows and `19` columns.
The data are not completely tidy because the subway routes serving each
station are spread across several columns.

### Combine the three datasets into a single tidy dataset

``` r
trash_wheel_df = bind_rows(
  mr_trash_wheel,
  professor_trash_wheel,
  gwynnda_falls_trash_wheel) |>
  relocate(wheel)
```

``` r

gwynnda_cigarette_butts = trash_wheel_df |>
```

The combined Trash Wheel dataset contains `1188` observations and `15`
variables. Key variables include the `Trash Wheel name`,
`dumpster number`, `collection date`, `trash weight`, `trash volume`,
and counts of different types of trash, such as `plastic bottles` and
`cigarette butts`. For the available data, Professor Trash Wheel
collected a total of `282.26` tons of trash, and Gwynnda Trash Wheel
collected `18,120` cigarette butts in June 2022.
